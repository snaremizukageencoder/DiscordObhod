> Антивирус может сработать на WinDivert.

> Этот инструмент способен использоваться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит компоненты WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Внесите папку с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение; при отсутствии понимания настроек рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (Cloudflare может оказаться заблокирован)
    * Windows 11 позволяет включить Secure DNS в параметрах самой системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Получите zip/rar-архив с [последнего релиза](https://github.com/snaremizukageencoder/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути

5. Запустите подходящий файл
    * Чтобы найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте ALT, FAKE и другие стратегии, пока не найдёте подходящий вариант**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменить режим обхода игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках (включено/выключено).
  - **`IPSet Filter`** — переключить обработку сервисов из `ipset-all.txt`.  
  Это удобно при проверке ресурса, который без zapret доступен, а с ним — нет.  
  В скобках показывается текущий режим:
    - `none` — ни один IP не проверяется
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров (Cloudflare, Amazon и других)


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При отдельном запуске стратегии, не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота
  - Запустите текстовый редактор от имени администратора и откройте файл `hosts` в созданной папке
  - Вставьте скопированное в конец `hosts` или замените ранее добавленную аналогичную запись
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что сохранение действительно выполнено.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/snaremizukageencoder/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение определённой стратегии способно произойти не сразу: сначала она работает, а позже перестаёт.
> В репозитории есть много вариантов обхода. Если ни один не помогает, создайте новую стратегию на основе существующей, изменив её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок

- Проверьте, что адрес нужного ресурса присутствует в доменных или IP-списках

- Запустите другие варианты (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сначала сохраните ресурсы и данные, которые добавляли самостоятельно
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце ответьте Y
- Удалите каталог zapret
- Скачайте свежую версию (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/snaremizukageencoder/zapret-discord-youtube/releases)
- Кликните по архиву ПКМ, откройте свойства и, если внизу справа есть "Разблокировать", нажмите её, затем примените изменения и выберите ОК
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не работает, закройте программу (иконка замка на панели задач) и выберите другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- Убедитесь, что в service.bat параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией по ссылке: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежний вариант перестал работать, переберите остальные стратегии.
- Дополнительная информация есть в [#251](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Для начала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, снова протестируйте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/snaremizukageencoder/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если результата нет, дополнительно включить `ipset any`

Учтите: `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если это не поможет, создайте обсуждение в разделе [Discussions](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Опишите её [здесь](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`
