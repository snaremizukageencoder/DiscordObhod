> Для работы zapret требуется WinDivert, который перехватывает и фильтрует сетевой трафик.  
> Такой инструмент может применяться разными программами, но сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства, после чего удаляет их и отправляет в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку zapret в исключения антивируса либо отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", затем выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic нужно активировать настройку "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать неправильно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/snaremizukageencoder/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не требуется

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите нужный скрипт
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегий

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск служб (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб: автозапускаемой стратегии и WinDivert
  - **`Game Filter`** - изменить режим обхода игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  В скобках показывается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - изменить режим обхода ресурсов из `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним нет.  
  В скобках отображается состояние:
    - `none` - список IP не участвует в проверке
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - загрузить из репозитория свежий `ipset-all.txt`
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - найти распространённые причины неработоспособности zapret.  
  В финале можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает его работу после внезапного сбоя
  - **`Run Tests`** - проверить стратегии:
    - `Standard tests` - протестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` не видно результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues/522)

### Не нашлась подходящая стратегия
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое открытого блокнота
  - Откройте файл `hosts` из появившегося каталога в текстовом редакторе, запущенном от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте соединение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/snaremizukageencoder/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно сохраняют работоспособность навсегда.**
> Обнаружение определённой стратегии может произойти спустя некоторое время, и тогда она перестанет работать.
> В репозитории собрано много вариантов. Если ни один не подходит, создайте новый на основе существующего, изменив его параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите компьютер
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце подтвердите действие клавишей Y
- Удалите каталог zapret
- Загрузите свежий архив (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/snaremizukageencoder/zapret-discord-youtube/releases)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть "Разблокировать", отметьте пункт, нажмите "Применить" и затем "ОК"
- Распакуйте архив в новый каталог в корне диска, исключив специальные символы и пробелы из пути
- Запускайте разные скрипты `general` и проверяйте доступность ресурсов. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочей стратегии настройте автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится в службах

1. Найдите имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ним бороться
- Переберите остальные стратегии, особенно если ранее всё работало
- См. также [#251](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- Откройте `service.bat` -> `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord через браузер: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею
- Если браузер тоже не подключается, проверьте все стратегии ещё раз: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/snaremizukageencoder/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не запускаются игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Попробуйте следующий общий порядок:
- через `service.bat` обновите ipset и включите `Game Filter`
- если этого недостаточно, включите также `ipset any`

У режима `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Поэтому не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Сообщите о ней [здесь](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Нужные адреса можно добавить в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
